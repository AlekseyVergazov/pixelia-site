# Скриншоты с телефона

Сюда кладём скриншоты редактора для сайта (как есть, с телефона):

- редактор с открытым фото;
- полоса инструментов со значками и числами;
- пары «до/после» — называть `имя-do.jpg` и `имя-posle.jpg`.

Готовые картинки для сайта (сжатые, WebP) делаются из этих файлов в `img/`, сами файлы здесь не меняются.
