# Что нужно заполнить

На сайте такие места помечены жёлтой рамкой `[ЗАПОЛНИТЬ: …]`. Когда пункт готов — заменить заглушку и вычеркнуть строку здесь.

| Что нужно | Где на сайте |
|---|---|
| Ссылка на RuStore | Главная, первый экран: кнопка «Скачать в RuStore» (`index.html`) |
| Ссылка на файл APK (сам APK в репозиторий не кладём) | Главная, первый экран: кнопка «Скачать APK» (`index.html`) |
| Почта для связи | Главная, подвал «Контакты» (`index.html`); политика, раздел 9 (`privacy/index.html`) |
| ФИО самозанятого | Главная, подвал «Реквизиты» (`index.html`); политика, раздел 1 (`privacy/index.html`) |
| ИНН | Там же, где ФИО |
| Дата, с которой действует политика | Политика, под заголовком (`privacy/index.html`) |
| Какие технические журналы ведёт хостинг | Политика, раздел 7 (`privacy/index.html`) — уточнить после выбора домена и хостинга |
| Проверка политики юристом | Политика: после проверки убрать жёлтую пометку «Черновик — проверить» |
| Скриншоты с телефона | Папка `screens/` → этап 3: телефон на первом экране (сейчас там заставка) и раздел «Скриншоты и до/после» (пока скрыт) |
| Домен | См. ниже «При переезде на свой домен» |

## При переезде на свой домен

Ссылки внутри сайта относительные и заработают сами. Полный адрес `https://alekseyvergazov.github.io/pixelia-site/` стоит только там, где он обязателен, — его нужно заменить на новый:

- `index.html` и `privacy/index.html` — картинка превью ссылок (`og:image`);
- `sitemap.xml` — адреса страниц;
- `robots.txt` — адрес `sitemap.xml` (поисковики читают `robots.txt` только в корне домена, поэтому заработает он именно после переезда);
- `404.html` — ничего менять не нужно, страница сама понимает, где лежит.
